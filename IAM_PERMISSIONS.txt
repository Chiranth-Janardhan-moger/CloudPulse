AWS IAM Permissions Required for Cloud Instance Monitor

To use all features of this application, your IAM user needs the following permissions:

=== REQUIRED PERMISSIONS ===

1. EC2 Permissions (for instance monitoring):
   - ec2:DescribeInstances
   - ec2:StopInstances

2. CloudWatch Permissions (for CPU metrics):
   - cloudwatch:GetMetricStatistics

3. Cost Explorer Permissions (for billing dashboard):
   - ce:GetCostAndUsage

=== IAM POLICY JSON ===

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ec2:DescribeInstances",
        "ec2:StopInstances",
        "cloudwatch:GetMetricStatistics",
        "ce:GetCostAndUsage"
      ],
      "Resource": "*"
    }
  ]
}

=== HOW TO ADD PERMISSIONS ===

1. Go to AWS IAM Console
2. Select your IAM user
3. Click "Add permissions" > "Create inline policy"
4. Choose JSON tab
5. Paste the policy above
6. Name it "CloudInstanceMonitorPolicy"
7. Click "Create policy"

=== NOTES ===

- Cost Explorer API is only available in us-east-1 region
- Billing data may take up to 24 hours to appear
- If you get "AccessDeniedException" for billing, ensure ce:GetCostAndUsage permission is added
- Cost Explorer must be enabled in your AWS account (Billing Dashboard > Cost Explorer)
