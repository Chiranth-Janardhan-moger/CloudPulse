Build a full-stack real-time Cloud Idle Instance Monitor application using React, Node.js, Express, Docker, Docker Compose, and AWS SDK v3.

The application should connect to AWS EC2 and CloudWatch services using AWS credentials stored in environment variables.

Features required:

* Fetch all EC2 instances
* Display instance details:

  * instance name
  * instance ID
  * instance type
  * instance state
  * launch time
* Fetch CPUUtilization metrics from CloudWatch
* Detect idle instances where CPU usage is below 5% for the last 7 days
* Show estimated monthly cost waste for idle instances
* Add a button to stop EC2 instances directly from the dashboard
* Create backend APIs for:

  * fetching instances
  * fetching metrics
  * stopping instances
* Handle invalid AWS credentials and API errors properly
* Build a clean dashboard UI
* Add status colors:

  * green for running
  * yellow for idle
  * red for stopped
* Add loading states and error states
* Add charts for:

  * CPU usage
  * idle percentage
  * estimated cost waste
* Auto refresh dashboard every 30 seconds
